## Sobre mí

Analista de seguridad especializado en detección de amenazas, respuesta a
incidentes y automatización con Python. Trabajo a diario con XDR/SIEM (Trend
Micro Vision One), Fortinet (FortiGate y FortiAnalyzer) y Active Directory, y
aplico IA a la investigación de amenazas y al análisis de phishing.

Casi todo lo que publico nace de un problema real del turno: si algo hay que mirar cada
mañana a mano, acaba siendo un repositorio.

## Proyectos

### Seguridad y threat intelligence

| Proyecto | Qué hace | Stack |
|---|---|---|
| [KEV Digest](https://github.com/eduolihez/kev-digest) | Vigila cada día el catálogo CISA KEV: detecta las vulnerabilidades con explotación activa confirmada, marca las usadas en ransomware y deja un registro versionado. Sin dependencias, sobre GitHub Actions. | Python · GitHub Actions |
| [Vision One CREM Report Generator](https://github.com/eduolihez/vision-one-crem-report-generator) | Genera informes de riesgo y exposición desde Trend Vision One, enriquecidos con NVD, KEV y EPSS, en HTML interactivo, Word y PDF. | Python · pandas · Flask |
| [Blue Team Hub](https://github.com/eduolihez/eduolihez.github.io) | Herramientas de respuesta a incidentes que corren en el navegador, playbooks y utilidades para SOC, incluido [KEV Watch](https://eduolihez.github.io/tools/kev-watch). | Astro · TailwindCSS |
| [NorthGate Browser](https://github.com/eduolihez/northgate-browser) | Fork de Mullvad/Firefox con detección de phishing on-device vía ONNX, sin telemetría. | Rust · ONNX · JavaScript |
