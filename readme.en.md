## About me

Security analyst working on threat detection, incident response and automation
with Python. Day to day I work with XDR/SIEM (Trend Micro Vision One), Fortinet
(FortiGate and FortiAnalyzer) and Active Directory, and I apply AI to threat
investigation and phishing analysis.

Almost everything I publish comes out of a real problem from a shift: if it has
to be checked by hand every morning, it ends up as a repository.

## Projects

### Security and threat intelligence

| Project | What it does | Stack |
|---|---|---|
| [KEV Digest](https://github.com/eduolihez/kev-digest) | Watches the CISA KEV catalog daily: detects vulnerabilities with confirmed active exploitation, flags the ones used in ransomware, and leaves a versioned record. No dependencies, running on GitHub Actions. | Python · GitHub Actions |
| [Vision One CREM Report Generator](https://github.com/eduolihez/vision-one-crem-report-generator) | Generates risk and exposure reports from Trend Vision One, enriched with NVD, KEV and EPSS, as interactive HTML, Word and PDF. | Python · pandas · Flask |
| [Blue Team Hub](https://github.com/eduolihez/eduolihez.github.io) | Incident response tools that run in the browser, playbooks and SOC utilities, including [KEV Watch](https://eduolihez.github.io/tools/kev-watch). | Astro · TailwindCSS |
| [NorthGate Browser](https://github.com/eduolihez/northgate-browser) | A Mullvad/Firefox fork with on-device phishing detection through ONNX, and no telemetry. | Rust · ONNX · JavaScript |

### Tools and applications

| Project | What it does | Stack |
|---|---|---|
| [Password Centinel](https://github.com/eduolihez/password-centinel) | A 100% local password manager: AES-256-GCM, TOTP/2FA and HIBP checking through k-anonymity. No backend and no user account. | JavaScript · WebCrypto |
| [BinCat](https://github.com/eduolihez/BinCat) | An SDK and Flask dashboard to generate, validate and revoke Fernet/JWT tokens. | Python · Flask · Cryptography |
| [eduolihez.com](https://github.com/eduolihez/eduolihez.com) | A trilingual portfolio and blog (ES/EN/CA): static Astro, a custom PHP/MySQL API, per-build CSP hashes and cookieless analytics. | Astro · TypeScript · PHP |
| [Dewi App](https://github.com/eduolihez/hackathon-Dewi) | Real-time water consumption monitoring. Prototype from the 8th TecnoCampus Hackathon. | Next.js · TypeScript |

### Closed projects

- [PromptMaster](https://eduolihez.com/projects/promptmaster/), a structured prompt engineering extension for ChatGPT, Claude and Gemini.
